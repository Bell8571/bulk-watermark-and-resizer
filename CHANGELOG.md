# Changelog

## 2.0.0 — 2026-06-22

### New features

- Settings export/import and reset defaults
- Preview filters (All / Source / Processed) and remove mode
- Batch statistics and per-file processing status
- Output filename patterns (`{basename}`, `{ext}`)
- Settings auto-save via `localStorage`
- EXIF-aware image orientation

### Improvements

- Modular `src/` architecture (Vite + ES modules)
- Electron portable desktop build
- Offline Font Awesome and JSZip dependencies
- Design tokens, focus-visible accessibility, collapsible debug console in production

### Packaging

- Release layout: `release/2.0.0/ProPhoto-Watermarker-2.0.0.exe`
- Branded application icon

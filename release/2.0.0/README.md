# ProPhoto Watermarker & Resizer 2.0.0 (Windows)

## Install

1. Download `ProPhoto-Watermarker-2.0.0.exe` from this folder.
2. Verify the file against `SHA256.txt` (optional).
3. Run the portable executable — no installer required.

## Requirements

- Windows 10 or later (64-bit)
- Enough disk space for your processed image batches

## Privacy

All image processing runs locally on your machine. No uploads to external servers.
